# AERO-RESCUE

🚁 Aero Rescue – Disaster Management & Emergency Response App
📌 Overview

Aero Rescue is an Android-based disaster management application designed to assist in emergency response and rescue operations.
The app focuses on real-time coordination, situational awareness, and rapid decision-making during disasters using a clean and scalable architecture.

It aims to support rescue teams and authorities by providing structured information flow, location awareness, and efficient resource management.

🎯 Key Objectives

Improve response time during disaster situations

Provide a centralized platform for rescue coordination

Enable scalable and maintainable emergency management solutions

🛠️ Tech Stack

Language: Kotlin

UI: Jetpack Compose

Architecture: MVVM (Model–View–ViewModel)

Dependency Injection: Dagger Hilt

Networking: Retrofit

State Management: StateFlow / LiveData

Backend/API: REST APIs

Tools: Android Studio, GitHub

✨ Features

📍 Location-based emergency awareness

🚨 Disaster and rescue information display

🧭 Structured navigation with Compose

🔄 Scalable architecture for future modules

🧩 Clean separation of concerns using MVVM

⚙️ Dependency Injection with Hilt for maintainability

🧱 Architecture

The project follows MVVM architecture:

Model: Handles data and business logic

View: Jetpack Compose UI

ViewModel: Manages UI state and business logic

Repository Pattern: Abstracts data sources

Hilt: Manages dependencies efficiently

This ensures:

Better testability

Loose coupling

Easy scalability
